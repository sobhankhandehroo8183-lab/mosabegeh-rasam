## 📌 معرفی پروژه

این پروژه یک **مسابقه نقاشی آنلاین** با طراحی جذاب و تعاملی است که توسط **موسسه فرهنگی هنری کتان آرتا رسام** برگزار می‌شود.  
صفحه با المان‌های تلویزیون قدیمی، ریموت کنترل، پرچم ایران و طراحی خلاقانه، تجربه کاربری متفاوتی را ارائه می‌دهد.

## ✨ ویژگی‌ها

- 📺 **تلویزیون تعاملی** با قابلیت قطع/وصل صدا
- 🎮 **ریموت کنترل** شبیه‌سازی‌شده
- 🏅 **مدال و پرچم ایران** در عنوان مسابقه
- 📱 **طراحی واکنش‌گرا** (Responsive)
- 🔊 **دکمه ولوم نارنجی** برای کنترل صدای ویدیو
- 🎨 **رنگ‌بندی گرم و جذاب** (طلایی، مشکی، قرمز)

## 🛠 تکنولوژی‌ها

- **Next.js 14** (React Framework)
- **CSS Modules / Global CSS**
- **React Icons**
- **GitHub Pages** برای میزبانی
